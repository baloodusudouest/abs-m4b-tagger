# abs-m4b-tagger
Écrit les métadonnées d'Audiobookshelf directement dans les tags des fichiers .m4b / .m4a / .mp3, en local, sans passer par Mp3tag ni télécharger les fichiers.  Le mapping des tags reprend celui du guide Plex-Audiobook-Guide (seanap / CaptZapp1729), mais la source de vérité est ta base Audiobookshelf au lieu d'Audible.com.
